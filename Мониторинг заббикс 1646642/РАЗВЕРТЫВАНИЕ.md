# Развёртывание мониторинга Windows + MSSQL в Zabbix

Комплект для каталога `C:\Работа\Заслон\Мониторинг заббикс 1646642`.

Два слоя, их можно включить вместе:

| Слой | Зачем | Что ставить |
| --- | --- | --- |
| Официальные шаблоны | постоянные графики ОС и СУБД | Windows by Zabbix agent + MSSQL by Zabbix agent 2 |
| Снимок `win.mssql.snapshot` | один JSON со счётчиками PerfMon и SQL, как в этом комплекте | YAML + UserParameter |

## 1. Хост Windows (SQL Server)

1. Установите **Zabbix agent 2** (для шаблона MSSQL нужен именно agent 2).
2. От администратора:

```powershell
cd "C:\Работа\Заслон\Мониторинг заббикс 1646642\01-Хост-Windows"
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-ZabbixAgent.ps1 -SqlInstance . -RestartAgent
```

Именованный инстанс: `-SqlInstance PRODATA`.

Скрипт кладёт файлы в `C:\zabbix\` и пишет `win-mssql-snapshot.conf` в `zabbix_agent2.d`.

3. В `zabbix_agent2.conf` должны быть:

```
Include=C:\Program Files\Zabbix Agent 2\zabbix_agent2.d\*.conf
Timeout=10
```

4. Учётка службы агента: чтение счётчиков производительности + к SQL — `VIEW SERVER STATE` / `VIEW PERFORMANCE STATE`.

Проверка на хосте:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\zabbix\Collect-WinMssqlSnapshot.ps1 -Stdout
```

Должен выйти один JSON. Затем в Zabbix: `zabbix_get -s ХОСТ -k win.mssql.snapshot` (или активная проверка).

## 2. Сервер Zabbix

1. **Сбор данных → Шаблоны → Импорт**  
   файл `02-Zabbix-сервер\template_win_mssql_snapshot.yaml`  
   шаблон: **Windows OS and MSSQL snapshot**

2. Хосту Windows назначьте:
   - Windows by Zabbix agent
   - MSSQL by Zabbix agent 2 (если настроен плагин)
   - Windows OS and MSSQL snapshot

3. Макросы MSSQL на хосте: `{$MSSQL.URI}`, `{$MSSQL.USER}`, `{$MSSQL.PASSWORD}`.  
   Пример URI: `sqlserver://localhost:1433`

Плагин: см. `02-Zabbix-сервер\Официальные-шаблоны.md`.

## 3. Разовая отправка без UserParameter

```powershell
cd "C:\Работа\Заслон\Мониторинг заббикс 1646642\03-Разовая-отправка"
.\Send-Snapshot.ps1 -ZabbixServer zabbix.example.ru -ZabbixHost SQL01
```

Ключи trapper совпадают с зависимыми элементами: `snapshot.os.cpu.util`, `snapshot.mssql.page_life_expectancy`, …

Для trapper-only смените тип master-элемента на Zabbix trapper или шлите сразу `snapshot.*`.

## 4. Что смотреть

Таблица ключей: `02-Zabbix-сервер\catalog-items.csv`.

ОС: CPU, privileged/user, очередь, Available MBytes, Pages/sec, paging file, задержки PhysicalDisk.  
SQL: Buffer cache hit ratio, PLE, Lazy writes, Batch Requests/sec, компиляции, память инстанса, блокировки, deadlock.

Локализованная Windows: только `perf_counter_en[...]`.
