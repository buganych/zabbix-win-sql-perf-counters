# Официальные шаблоны Zabbix (рекомендуется для постоянных графиков)

Не подменяйте их коллектором, если агент 2 уже стоит. Коллектор — запасной путь
(один JSON на ОС+SQL) и разовая диагностика.

## Windows (ОС)

Шаблон: **Windows by Zabbix agent**
(или Windows by Zabbix agent active — если только активные проверки).

Что закрывает: CPU, память, paging, PhysicalDisk (LLD), сеть, uptime.

Документация: https://www.zabbix.com/integrations/windows

Ключи вида:
  system.cpu.util
  vm.memory.size[used]
  perf_counter_en["\Processor Information(_Total)\% Privileged Time"]
  perf_instance_en.discovery[PhysicalDisk]

На локализованной Windows только perf_counter_en, не perf_counter.

## SQL Server (СУБД)

Шаблон: **MSSQL by Zabbix agent 2**
Нужен Zabbix agent **2** и плагин MSSQL.

Файл: %ProgramFiles%\Zabbix Agent 2\zabbix_agent2.d\plugins.d\mssql.conf

  Plugins.MSSQL.Timeout=15
  Plugins.MSSQL.Sessions.Default.Uri=sqlserver://localhost:1433
  Plugins.MSSQL.Sessions.Default.User=zabbix
  Plugins.MSSQL.Sessions.Default.Password=...

Макросы хоста:
  {$MSSQL.URI}       sqlserver://localhost:1433
  {$MSSQL.USER}
  {$MSSQL.PASSWORD}
  {$MSSQL.HOST}      для net.tcp.service
  {$MSSQL.PORT}      1433

Учётка SQL: CONNECT + VIEW SERVER STATE (VIEW PERFORMANCE STATE на новых версиях)
+ VIEW ANY DATABASE. Не используйте sa.

Один элемент забирает все глобальные счётчики:
  mssql.perfcounter.get["{$MSSQL.URI}","{$MSSQL.USER}","{$MSSQL.PASSWORD}"]

Документация: https://www.zabbix.com/integrations/mssql

## Что импортировать из этого комплекта

Файл: template_win_mssql_snapshot.yaml
Шаблон: Windows OS and MSSQL snapshot
Ключ master-элемента: win.mssql.snapshot (Zabbix agent, активный)

Нужен UserParameter с хоста (01-Хост-Windows\Install-ZabbixAgent.ps1).
Timeout агента ≥ 10 с.

Импорт: Сбор данных → Шаблоны → Импорт → YAML.
Затем назначьте шаблон хосту Windows с SQL Server.
